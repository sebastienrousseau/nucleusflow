# Support

Welcome to NucleusFlow. Here are the channels for help, issue reporting, and general inquiries.

## Documentation & Help

- **API Documentation**: Comprehensive documentation is available at [docs.rs/nucleusflow](https://docs.rs/nucleusflow).
- **Architecture & Design**: Detailed technical specifications reside in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
- **Development & Contribution**: Development workflow and local CI reproduction are documented in [`DEVELOPMENT.md`](DEVELOPMENT.md).

## Reporting Bugs

To report a bug, please open a GitHub issue providing:
1. Steps to reproduce the issue.
2. The exact Rust toolchain and operating system (`rustc --version`).
3. Minimal reproducible example or code snippet.
4. Expected versus actual behaviour.

## Security Disclosures

Do NOT report security vulnerabilities via public issues. Follow the private disclosure instructions in [`SECURITY.md`](SECURITY.md).
